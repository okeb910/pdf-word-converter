PDF ↔ Word/PPT 批量转换工具 v0.5.1 Windows 便携版使用说明
==========================================

版本状态
--------
- 本说明对应 GitHub 正式发布的 v0.5.1 Windows 便携版。
- 当前完整自动化测试结果为 289 passed, 1 skipped。便携版已通过 x64、版本资源、无控制台、中文空格路径启动、内置组件、SHA-256 和 Windows Defender 自定义扫描验收。

系统要求
--------
- 64 位 Windows 10 或 Windows 11。
- 目标电脑不需要安装 Python，也不会在启动时运行 pip。
- 便携版暂未数字签名，Windows SmartScreen 可能显示“未知发布者”。

启动与添加文件
--------------
- 双击 PDF-Word-PPT-Converter-v0.5.1-Portable-x64.exe。
- 可点击添加按钮，也可把 PDF、DOCX、PPT 或 PPTX 拖入转换队列。
- PDF 可直接拖到“PDF → Word”或“PDF → PowerPoint”目标块。
- Word/PPT 拖入普通队列后自动转换为 PDF。
- 一次拖入多种源格式会整批拒绝，请分开处理。
- 请直接双击运行，不要使用“以管理员身份运行”，否则 Windows 可能阻止资源管理器拖放。

转换方向
--------
- PDF → Word：可选 Word 原生可编辑模式、仅扫描件/纯图形图片模式或 LibreOffice 兼容模式；图片模式只在用户明确选择或确认后使用。
- Word → PDF：优先 Word，不可用时使用 LibreOffice。
- PDF → PowerPoint：内置自适应高清图片模式，每页生成一张幻灯片。
- PPT/PPTX → PDF：优先 PowerPoint，不可用时使用 LibreOffice。

PDF → Word 精度选择
-------------------
- 开始转换时，程序会在后台逐文件检查全部页面中的可选择文字、字体映射、表单、复选/勾选符号、矢量图形和表格迹象；窗口与取消按钮保持可响应。
- 20 页以内的文档继续逐页提取线框表格、无边框表格、单元格拓扑和四边证据。超过 20 页的长文档会快速扫描全部页面文字和风险标记，不再逐页重复执行多轮高成本表格重建。
- 主检测未确认表格、长文档未建立逐格基线、检测到 U+FFFD 替换字符/私用区字符，或勾选状态无法自动证明时，只要有可编辑引擎就继续转换；批次完成后显示“转换质量提醒”，列出需要对照原 PDF 检查的文件和原因，不再因为检测不确定而直接不给输出。
- 只要 PDF 含任何可选择文字，不论是否已经明确识别为表格，都只允许 Word/LibreOffice 重建；即使手动选择图片模式也会要求改用可编辑引擎，LibreOffice 失败后同样禁止回退图片。整页图片不会被静默选择，也不会自动作为失败兜底。
- 每个文件独立选择引擎。只有用户已选择图片模式，或对扫描件/纯图形高风险文件在提示中明确选择“是”，并且预检成功证明完全没有可选择文字时，才使用整页高清图片：
  - 选择“是”：只把符合上述条件的文件改用整页高清图片。
  - 选择“否”：继续 Word/LibreOffice 可编辑模式，识别结果可能不完整。
  - 选择“取消”：本批暂不转换。
- PDF 预检发生异常时该项直接失败并继续批次，不会未经检查进入转换，也不会生成图片替代文件；预检后被替换或改写的源文件也会停止并要求重新加入。
- 可编辑表格同时含复选框、表单控件、疑似矢量勾选或 Symbol/Wingdings 字体时，目前无法逐项证明状态未改变，因此继续使用可编辑引擎并在完成后警告，不提供静默图片回退。
- 检测出表格后，程序记录源 PDF 的精确行列矩阵、每个单元格的行列跨度、列宽几何，以及每个逻辑单元格 top/left/bottom/right 四条边的可见描边。Word 如果把一个源单元格拆成多个相邻格，只在几何、逐格文字、样式和外边框能够唯一证明归属时进行事务式合并；拓扑正确但边框缺失或写成 nil 时仍会按源证据恢复。真实合并格内部不会误加线，无边框表格不会被强制套用网格。
- 对 20 页以内且源表格基线完整的文档，修复后执行硬门禁：DOCX 必须能正常打开并包含真实 Word 表格；源表与 Word 表格的数量和顺序、有效行列矩阵、独立单元格数、每格行列跨度、每格规范化文字、每格四边状态和总表格字符数必须完全一致。少边、多边、少字或文字错格都会拒绝输出。空白表格也必须凭完整拓扑通过，不再使用“至少保留 80%”的宽松阈值。
- 门禁拒绝照片加伪表格、全页大图、文字错格或换格、错误合并、隐藏/近白/透明/异常小字号文字、不可证明可见的表格、文档保护、写保护和锁定内容控件。
- 每项转换先写入同目录私有 .partial.docx。源基线可靠时只有修复和硬门禁全部通过才发布；源结构或字体映射本身无法可靠验证时，只要 DOCX 可正常打开就保留结果，并在完成弹窗列出严格校验差异。真正的转换异常、损坏 DOCX、可靠基线下的确定漏字/错格和源文件变化仍会失败并清理不完整文件。
- LibreOffice 转换文字文件失败时不会改用图片；没有 Word/LibreOffice 时该项失败，不会生成照片。只有没有可编辑内容保护、LibreOffice 确认为导出过滤器失败且用户再次明确同意时，才允许图片重试。
- v0.5.1 不再执行旧版的猜测性 DOCX 后处理。拓扑完全通过门禁后，只对单个近满页大型表格执行有证据约束的版式修复：清理系统性重复的文字方框；仅当所有行都有有效显式高度时使用固定行高；仅对符合条件的表格收紧页边距和单元格上下内边距。孤立的合法文字边框和无法证明安全的格式不会被改写。
- 图片模式默认约 300 DPI，并限制异常大页面的长边与总像素；即使 1 DPI 仍超限时会明确报错，不执行 OCR。
- 短文档可靠基线下的硬门禁能证明行列拓扑和逐格文字一致；提醒模式只证明结果可打开，不证明内容完全一致。PDF 已丢失的字体、精确列宽、行高和分页语义仍可能变化；重要表格、合同、试卷、年报和表单转换后必须人工核对。

环境检测
--------
- Word、PowerPoint、LibreOffice、内置组件和 winget 会并行检测并逐项显示。
- Word、PowerPoint 和 LibreOffice 只做注册或路径浅检测，不会在启动时打开外部程序。
- 已发现的外部引擎会在首次实际转换时验证，因此启动检测通常很快。
- 当前转换方向所需检测完成后即可操作，不等待无关引擎。
- 启动检测不会主动要求安装 Office；只有真正缺少所选引擎时才提示。
- Office 需要许可证和 Microsoft 账号，程序不会提供许可证。

PDF → PowerPoint 说明
---------------------
- 不需要安装 Microsoft PowerPoint。
- 以原页面外观还原为目标，横竖混合页面等比居中且不裁切。
- 幻灯片中的内容是整页图片，文字、表格和图形不能单独编辑。

批量转换与输出
--------------
- 同一批次只处理一种源格式，程序会串行处理。
- 默认输出到各源文件目录，也可选择统一输出目录。
- 不覆盖已有文件，依次使用：原名、原名_converted、原名_converted_2。
- 取消会在 PDF 预检的逐页和表格识别阶段协作停止，并每秒显示等待时间；如果外部转换引擎已经开始处理当前文件，则等待该文件完成或失败，不会强制结束进程。
